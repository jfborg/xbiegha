# Local photo analysis assets

Generated by `node scripts/prepare-vision.mjs` before development or build. The models are pinned by SHA-256; an upstream change fails the build until reviewed. Runtime files come from the exact versions in pnpm-lock.yaml.

- MediaPipe Face Landmarker (float16, v1), Google / MediaPipe, Apache-2.0. Tasks Vision runtime 0.10.35. See LICENSE-MediaPipe.txt.
- FrameFind glasses classifier v1, distributed by the MIT-licensed [FrameFind project](https://github.com/moraxh/FrameFind). Core 0.4.1. See LICENSE-FrameFind.txt.
- ONNX Runtime Web 1.25.1, Microsoft, MIT. WASM-only build. See LICENSE-ONNXRuntime.txt.

All are served from this website at runtime. No photograph, landmark, probability or analysis is transmitted to the model hosts. The checker is screening software, not a certified biometric or official-acceptance service. Thresholds are screening heuristics and are not represented as official authority tolerances.
